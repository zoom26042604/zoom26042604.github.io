Politique de confidentialité

Dernière mise à jour : 13 novembre 2026

Objet

Cette application OAuth est utilisée exclusivement par son propriétaire, via l'outil open source rclone, pour accéder à son propre compte Google Drive (lecture, écriture, synchronisation et sauvegarde de fichiers).

Données consultées

L'application accède aux fichiers et métadonnées Google Drive du compte autorisé, uniquement dans le but d'exécuter les commandes lancées par l'utilisateur.

Stockage et partage

  • Les données transitent directement entre Google Drive et l'ordinateur de l'utilisateur.
  • Aucune donnée n'est collectée, stockée ou traitée sur un serveur tiers.
  • Aucune donnée n'est vendue, partagée ou transmise à qui que ce soit.
  • Les jetons d'accès sont conservés localement dans le fichier de configuration rclone de l'utilisateur.

Utilisation des données Google

L'utilisation des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (Limited Use).

Révocation

L'accès peut être révoqué à tout moment depuis myaccount.google.com/permissions.
